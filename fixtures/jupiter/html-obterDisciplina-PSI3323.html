Eng de Sistemas Eletrônicos
 
Disciplina: PSI3323 - Laboratório de Eletrônica I
Electronics Laboratory I

Créditos Aula: 3
Créditos Trabalho: 0
Carga Horária Total: 45 h
Tipo: Semestral
Ativação: 01/01/2025       Desativação:

 
Ementa 
Circuitos Retificadores, Reguladores de Tensão Lineares, Fontes Chaveadas de Tensão, Amplificadores Operacionais, Circuitos Multivibradores, Amplificadores de Pequenos Sinais, Circuitos Integrados CMOS, Amplificadores Diferenciais.
 
Rectifier Circuits, Linear Voltage Regulators, Switched Voltage Sources, Operational Amplifiers, Multivibrator Circuits, Small Signal Amplifiers, CMOS Integrated Circuits, Differential Amplifiers.
 
 
Objetivos 
Os objetivos de aprendizagem dessa disciplina são os seguintes:
- Identificar e escolher os componentes para a montagem de um determinado circuito eletrônico                        
- Implementar um circuito eletrônico simples        
- Desenvolver um projeto simples utilizando os circuitos implementados anteriormente 

As competências e habilidades a serem desenvolvidas nessa disciplina são as seguintes:
- Competência: Modelar e Simular Fenômenos e Sistemas
Habilidades: Identificar componentes dos sistemas, compreender detalhadamente fenômenos, validar o modelo
- Competência: Desenvolver projetos de engenharia
Habilidades: Projetar uma solução adequada aos objetivos do projeto, Validar solução.
 
The learning objectives of this course are:
- Identify and choose the components for assembling a given electronic circuit
- Implement a simple electronic circuit
- Develop a simple project using previously implemented circuits

The competencies and skills to be developed in this course are the following:
- Competence: Model and Simulate Phenomena and Systems
Skills: Identify system components, understand phenomena in detail, validate the model
- Competence: Develop engineering projects
Skills: Design a solution appropriate to the project objectives, Validate solution.
 
 
Conteúdo Programático 
1) Circuitos Retificadores.
2) Reguladores de Tensão Lineares.
3) Fontes Chaveadas de Tensão.
4) Amplificadores Operacionais. 
5) Circuitos Multivibradores usando CI555.
6) Amplificadores de Pequenos Sinais.
7) Circuitos Integrados CMOS: MOSFET (Tipo N e Tipo P), inversor lógico, chave analógica. 
8) Amplificadores Diferenciais.
9) Desenvolvimento de um projeto eletrônico básico.
 
1) Rectifier Circuits.
2) Linear Voltage Regulators.
3) Switched Voltage Sources.
4) Operational Amplifiers.
5) Multivibrator Circuits using CI555.
6) Small Signal Amplifiers.
7) CMOS Integrated Circuits: MOSFET (Type N and Type P), logic inverter, analog switch.
8) Differential Amplifiers.
9) Development of a basic electronic project.
 
 
Instrumentos e Critérios de Avaliação
     
Método de Avaliação
Avaliação diversificada com atividades em grupo (relatórios), testinhos e provas práticas individuais.
Critério de Avaliação
Média final maior ou igual a 5,0
Norma de Recuperação
Prova escrita realizada no período reservado às avaliações de recuperação.
 
 
Bibliografia

[2] Apostila de Laboratório de Eletrônica I, vários autores, editada pelo Martino, J. A., PSI/EPUSP, 2013.
